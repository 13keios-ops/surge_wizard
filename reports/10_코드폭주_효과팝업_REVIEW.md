### 1-2. ★ 가장 틀리기 쉬운 곳 — 코드를 눈으로 확인했다

```dart
int _backlashDamage(Spell spell, int percent) {
  final base = max(_battle.spellPower(spell), kBacklashMinPower);
  return (base * percent / kPercentBase).round();
}
```

**`it.power`가 없다.** 지시서가 가장 강조한 것이 지켜졌다.
경고 주석("곱하면 전력 시전 실패가 곧 자살이 된다")까지 남겼다.

### 1-3. 자해 상한이 「합산 후 절단」인지

```dart
void _applySelfDamage(SurgeOutcome out) {
  final cap = (_battle.playerMaxHp * kSurgeSelfDamageMaxRatio).floor();
  final dmg = min(out.selfDamage, cap);
  _battle.dealToPlayer(dmg);
```

✅ 효과마다 입히지 않고 `SurgeOutcome.selfDamage`에 모았다가 **한 번에** 자른다.
`dealToPlayer`가 그 뒤에 방어막을 흡수한다. **순서까지 정확하다.**

`self_damage` · `self_damage_spell` · **음수 `chain_cast`가 전부 같은 통에 들어간다.**
음수 연쇄를 빼먹기 쉬운데 들어가 있다.
