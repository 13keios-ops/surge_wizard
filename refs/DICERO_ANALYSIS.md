# 딸깍 다이스(Dicero) 실플레이 분석

**수집 방법**: 사용자의 갤럭시 S20+에 무선 디버깅(adb)으로 접속해 직접 플레이하며 캡처.
2026-08-31, 게임 버전 v1.7.2. 챕터1을 10층까지 플레이(사망)했다.
스크린샷 22장은 같은 폴더(`refs/dicero/`)에 번호순으로 있다.

> 베끼기 위한 문서가 아니라, 우리 게임(`surge_wizard`)이 "조악해 보이는"
> 원인을 짚기 위한 기준이다. GAME_DESIGN.md 9.5절을 실제 화면으로 대체한다.

## 1. 전투 화면 구도 — 원근법

`16_전투화면_전체구도_최종참고.png`, `19_주사위5개_전체트레이_노드트랙.png`

| 영역 | 내용 |
|---|---|
| 최상단 좌 | Lv.5 + 경험치바 / ⚔10/20(진행) / 9라운드 / x1(배속) |
| 최상단 우 | ⏸ 일시정지, 💀 보스 미리보기 |
| 좌측 세로 | **노드 트랙** — ⚔전투 / 💀정예 / 👹보스20 아이콘이 위로 이어짐 |
| 상단 40% | **적**: 작게, 멀리. 발밑 노란 타원 링(타겟), HP바, 예고 아이콘 |
| 중앙 | **플레이어 뒷모습**: 크게, 가까이. HP바 위에 숫자를 얹음 |
| 중하단 | 공격력 ◇16 + 발동 족보 배너 「원 페어 x1.5」 |
| 하단 | **주사위 트레이 5칸** (미해금은 자물쇠), 각 칸 아래 +N |
| 그 아래 | 🔄 2/3 리롤 잔여 |
| 최하단 | 좌: 스킬북 / 중앙: 큰 **공격** 버튼 / 우: 주사위 인벤토리 |

**우리와 결정적 차이 4가지**

1. **원근 구도** — 좌우 대치가 아니라 복도 안쪽을 보는 구도. 적은 위쪽에 작게,
   플레이어는 아래쪽에 크게 **뒷모습**. 화면에 깊이가 생긴다.
2. **배경이 밝다** — 눈밭·달·기둥이 밝은 하늘색~흰색. (우리는 전체가 어두운 보라)
3. **적이 여럿** 등장하고 **탭으로 타겟 선택** (`11`)
4. **HP 숫자를 바 위에 겹쳐** 쓴다

## 2. 족보가 덧셈이 아니라 곱셈

`20_사망결과화면_핵심참고.png` 하단, `16` 중앙

- 「**원 페어 x1.5**」, 「하이 다이스 x1」 — 족보는 **대미지 배수**다.
- 배너가 항상 화면에 떠 있어 지금 몇 배인지 계속 보인다.
- 우리는 페어 = 판정값 +3 (덧셈). 설계 자체가 달라 그대로 못 가져오지만,
  **"지금 뭐가 발동 중인지 배너로 상시 표시"** 는 배울 만하다.

## 3. 주사위 조작 — 우리와 정반대

`06`, `07`, `05`

- **주사위를 탭하면 그 주사위만 즉시 다시 굴러간다.** 리롤 버튼이 없다.
- 굴리는 동안 주사위가 **3D 큐브처럼 공중에서 회전**하다 착지.
- 스킬 장착 주사위는 **파란 불꽃이 계속 타오른다** (`14`) — 일반과 확연히 구분.
- 주사위는 성장한다: 1개 → 5개 (잠긴 칸은 자물쇠로 미리 보여줌).

> 우리는 3d6 고정 + "탭 잠금 → 리롤 버튼". 딸깍 방식이 한 단계 짧지만,
> 우리는 **잠금이 전략의 핵심**이라 유지하는 게 맞다. 대신 잠금 상태를
> 훨씬 강하게(불꽃/발광) 표시할 것.

## 4. 타격 연출 — 매 공격마다 터진다

`04_공격_타격순간_화면플래시.png`

한 번의 공격에 네 가지가 동시에:

1. **화면 전체가 하얗게 밝아진다** (어두운 배경 → 흰 배경으로 확 뒤집힘)
2. 금색 다이아 파티클 4~5개가 적에게 날아감
3. 적 스프라이트가 찌그러짐
4. 화면 **오른쪽 가장자리에 「피해 6」 배너** 슬라이드 인

> 우리는 대성공에만 플래시. 딸깍은 **매 타격마다** 화면을 뒤집는다.
> 대미지 숫자도 캐릭터 위가 아니라 **가장자리 고정 배너**라 항상 읽힌다.

## 5. 보상 화면 — 가장 크게 배울 부분

`12_레벨업_스킬3택_핵심참고.png` (금색), `17_스킬3택_파란등급카드.png` (파란색)

- 레벨업 시 **화면 전체가 카드 등급 색으로 물든다** (금색/파란색)
- 상단에 장식 헤더: 주사위 아이콘 + 「스킬 선택」 + 좌우 장식선, 우상단 스킬북
- **가로 전체폭 배너 카드 3장**이 세로로 쌓인다:

```
┌──────────────────────────────────────────────┐
│ ┌────┐   ┌────────────────────┐    [추천]    │
│ │아이콘│   │   검영 레벨+2         │            │
│ └────┘   └────────────────────┘            │
│        리롤 횟수 소모 시, 검기 2스택 획득          │
└──────────────────────────────────────────────┘
```

- 이름은 **알약 모양 띠 안에**, 설명은 그 아래 한 줄
- 추천 항목에 빨간 **「추천」 뱃지**
- 카드 배경색 = 등급 (파랑 → 금색)
- 스킬을 고르면 **「주사위 선택」** 이 이어져 어느 주사위에 붙일지 지정 (`13`)

> 우리 보상 화면은 좁은 세로 카드 3장을 가로로 늘어놔 글자가 잘린다.
> **가로 배너 3장 세로 배치**가 정답이다.

## 6. 이벤트 노드 — 대화상자를 쓰지 않는다

- **룰렛** (`08`): 개구리 마법사가 화면 절반을 차지하는 큰 일러스트로 등장,
  그 아래 실제로 돌아가는 룰렛 휠. 버튼 하나(「운 테스트」).
- **보물** (`18`): 파란 **리본 배너** 「보물 발견」 + 큰 황금 상자 + 「보물 열기」

> 우리 상점은 글자만 있는 `AlertDialog`. **NPC/오브젝트 그림 + 큰 버튼**으로
> 바꾸면 체감이 완전히 달라진다.

## 7. 사망 결과 화면

`20_사망결과화면_핵심참고.png`

- 상단: 큰 **황금 검 기념비**(땅에 꽂힌 검 = 죽음의 표식)
- **「정말 아쉽네요!」** 큰 흰 글씨가 **파란 리본 스워시** 위에
- **챕터1** + 거대한 노란 숫자 **10** (도달 층수 = 점수)
- 「보상 획득」 구분선 + 보상 타일 2개 (🪙x163, EXPx60) — 하늘색 테두리 박스
- 노란 **「돌아가기」** 버튼 하나

> 우리 결과 화면과 구조는 비슷하나, **도달 층수를 훨씬 크게** 쓰고
> 리본 배너로 감정을 실었다.

## 8. 로비 — 캐릭터가 살아 있다

`21_로비_모닥불장면_스테이지카드.png`

- 상단: 아바타+레벨바, 전투력🛡100, 💎젬, 🪙골드, 🍖스태미나 130/60
- 중앙: **육각형 스테이지 카드** — 배경 미리보기 + 요구 전투력🛡120 +
  스테이지명 + 최고기록 9/20 + 큰 챕터 번호
- 중단: **주인공이 모닥불 앞에 앉아 쉬는 큰 픽셀 장면** (검을 땅에 꽂아둠)
- 하단: 「신규 게임 🍖x10」 파란 버튼 + 5칸 탭바(다이아 아이콘, 4개 잠김)

> 로비가 메뉴 나열이 아니라 **하나의 장면**이다.

## 9. 아트·UI 스타일 정리

- **팔레트**: 밝은 하늘색/흰색 배경 + 채도 높은 포인트(금색·빨강·청록)
- **패널** (`15`): 연한 하늘색 바탕 + 흰 픽셀 테두리 + **모서리 장식**
- **버튼**: 두꺼운 테두리 + 아래 그림자(입체 픽셀 버튼), 노랑=주요/파랑=보조
- **폰트**: 굵은 픽셀 계열. 숫자는 크고 노란색
- **캐릭터**: 32~48px급, **외곽선 없이 부드러운 셰이딩**, 머리 크고 귀여움
- **적**: 눈이 크고 단순한 실루엣. 색으로 종류 구분
- **뱃지/라벨**: 「추천」 빨강, 「사용 중」 초록, 「Lv.2」 검정 — 작고 선명

**적용하지 않을 것** (우리 설계와 충돌):
- 주사위 탭 = 즉시 리롤 → 우리는 **잠금 전략**이 핵심이라 유지
- 주사위 개수 성장(1→5개) → 기획서상 **3d6 고정**
- 스킬을 주사위에 장착 → 우리는 **주문 손패 3장** 구조
- 족보 = 곱셈 배수 → 우리 확률표(3.4절)가 덧셈 기준이라 유지
- 스태미나(🍖)로 판을 제한 → 기획서 10절 "하지 않을 것"에 가까움
