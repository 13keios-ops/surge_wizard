# 지팡이 15종 — 제작 요청서

> **첨부된 `wizard_body.png`(마법사 몸)가 모든 시각 기준입니다.**

## 0. 이 문서와 프로젝트 지침의 관계 — 먼저 읽어 주세요

**출력 형식은 이 대화창의 「그래픽 에셋 제작 지침」을 그대로 따릅니다.**  
PNG 원본 · 실제 알파 채널의 투명 배경 · 한 파일에 하나의 에셋 ·  
JSON 메타데이터 · ZIP 묶음 · 라이선스와 독창성 — **여기서 다시 적지 않습니다.**

### ⚠ 다만 지침 3절과 일부가 다릅니다

지침 3절은 **「해상도·캔버스 크기·색상 수를 성급하게 고정하지 않는다」**고 정해 두었습니다.
이 작업에서는 **레이어 정합에 필요한 크기 규격과 캔버스 체계만 고정**합니다.

**색상 수 자체를 PNG 전체의 절대 개수로 강제하지 않습니다.**  
`wizard_body.png`는 시각적으로 제한된 픽셀 팔레트를 사용하지만, 실제 파일에는 안티앨리어싱·반투명 경계·광원 혼합에서 생긴 파생색이 존재합니다. 따라서 지팡이도 **주요 디자인 팔레트와 명암 구조는 제한하되, 출력 PNG를 24~32색으로 양자화하거나 파생색을 제거하지 않습니다.**

**이유**: 지팡이는 **첨부된 캐릭터 위에 겹쳐지는 레이어**라, 캐릭터와 크기·밀도가 맞지 않으면 게임에서 사용할 수 없습니다. 동시에 색 수를 기계적으로 제한하거나 알파를 단순화하면 캐릭터보다 거칠고 빈약해져 화풍 일관성이 깨집니다.

지침 12절의 우선순위에 따라 **사용자의 최신 명시적 요구인 이 문서가 우선합니다.**  
그 외의 모든 항목은 지침을 그대로 따릅니다.

## 1. 무엇을 만드나

세로 화면 모바일 게임의 **마법사 장비 「지팡이」 15종**입니다.  
등급은 **일반 → 고급 → 희귀 → 영웅 → 전설** 5단계, 등급당 3종입니다.

### 지팡이는 캐릭터 위에 겹쳐지는 레이어입니다

게임에서 마법사는 **네 장이 겹쳐** 한 인물이 됩니다.

```text
로브 → 몸 → 모자 → 지팡이   (지팡이가 맨 앞)
```

그래서 **15종이 전부 「같은 길이·같은 자세」**여야 합니다.  
장비를 바꿔 껴도 어긋나지 않아야 하기 때문입니다.

### ★ 제작 방식

- **지팡이 한 종을 한 번에 독립적으로 제작합니다.**
- 여러 지팡이를 한 장에 함께 생성한 뒤 잘라내는 방식은 사용하지 않습니다.
- 한 에셋의 형태·광원·재질·오라가 완성된 상태에서 크기와 위치만 규격에 맞춥니다.
- 규격을 맞추기 위한 후처리 과정에서 **강제 색상 양자화, 알파 이진화, 과도한 축소 후 재확대**를 하지 않습니다.
- 크기 조정이 필요한 경우 원본 품질과 픽셀 구조를 보존하는 방식으로 처리하고, 최종 결과를 `wizard_body.png` 옆에 두고 시각 검수합니다.

## 2. ★ 규격 — 첨부된 캐릭터에 맞춥니다

첨부 파일 `wizard_body.png`를 재면 이렇습니다.

| | 크기 |
|---|---|
| **캐릭터 신장** | **599px** |
| 머리 전체 (머리카락 포함) 폭 | 287px |
| **얼굴 (피부만) 폭** | **169px** |

### 2-1. 길이와 헤드

| 항목 | 값 |
|---|---|
| **지팡이 길이** | **캐릭터 신장과 비슷하게** — 신장의 **95~100%** (약 570~600px) |
| **헤드(끝 장식) 폭** | **최대 150px.** 캐릭터 얼굴(169px)보다 확실히 작게 |

**길이는 15종이 전부 같습니다. 등급에 따라 커지는 것은 헤드뿐입니다.**

| 등급 | 헤드 폭 (대략) |
|---|---|
| 일반 | **70px** |
| 고급 | **90px** |
| 희귀 | **110px** |
| 영웅 | **130px** |
| 전설 | **150px** |

> ⚠ **빛·입자·오라까지 포함한 폭**입니다.  
> 결정 주위에 눈꽃이 흩날리거나 불티가 튀면 **그것까지 합쳐서** 해당 등급의 헤드 폭 안에 들어와야 합니다.  
> 헤드가 얼굴보다 커지면 게임 화면에서 **캐릭터 얼굴을 가립니다.**

### 2-2. 자세와 위치

- **지팡이만 그립니다.** 몸·손·팔을 그리지 마세요.
- **세워 든 자세.** 아래쪽이 바닥을 짚는 형태. 눕히거나 휘두르지 마세요.
- **캔버스 가로 중앙**에 세로로 곧게 배치합니다.
- **그림자를 그리지 마세요.** 캐릭터 쪽에 이미 있습니다.
- 휘어진 헤드나 떠 있는 장식은 허용하지만, **전체 무게중심과 샤프트 축은 세로 정렬**을 유지합니다.

### 2-3. 캔버스

| 항목 | 값 |
|---|---|
| 캔버스 비율 | **세로 1:2 정도** (예: 400 × 800) |
| 캔버스 채움 | **지팡이가 세로의 약 90%를 채우게.** 여백을 크게 두지 마세요 |

> 캔버스를 크게 잡고 지팡이를 작게 그리면 게임에서 확대해 쓰게 되어 **캐릭터보다 흐릿해집니다.**  
> 반대로 헤드·오라가 잘리지 않도록 최소한의 안전 여백은 둡니다.
>
> *(파일 형식·투명 배경·한 파일에 하나 — 지침을 따릅니다)*

### 2-4. ★ 색과 명암 — 「주요 팔레트」는 제한하되 출력 색 수를 강제하지 않습니다

| 항목 | 기준 |
|---|---|
| **주요 디자인 팔레트** | 대략 **24~32개의 핵심색**을 중심으로 구성 |
| 한 재질의 기본 명암 구조 | **3~5개의 큰 명암 단계**를 중심으로 읽히게 구성 |
| 안티앨리어싱·반투명·발광 파생색 | **허용. 색 수 제한에서 제외** |
| 최종 PNG 전체 색 수 | **고정하지 않음** |

**24~32색은 디자인 단계의 핵심 팔레트 지침이지, PNG 파일의 실제 RGBA 고유색 개수 제한이 아닙니다.**

다음은 허용합니다.

- 외곽선의 부드러운 색 변화
- `wizard_body.png`와 비슷한 가장자리 안티앨리어싱
- 발광 코어 주변의 제한된 반투명 혼합
- 보석·금속·마법광의 작은 하이라이트 파생색
- 오라와 에너지의 자연스러운 알파 단계

다음은 금지합니다.

- 완성된 이미지를 **24~32개의 실제 색으로 강제 양자화**하는 것
- 반투명 가장자리를 모두 제거하여 알파를 `0/255`만 남기는 것
- 넓은 면 전체에 사진처럼 매끈한 연속 그라디언트를 까는 것
- 캐릭터보다 훨씬 많은 미세 명암 단계를 사용해 반실사처럼 보이게 하는 것

**넓은 재질 면은 픽셀 클러스터가 읽히는 큰 명암 덩어리로 처리합니다.**  
단, 광원·마법·외곽 경계에서 생기는 보조색까지 삭제해서는 안 됩니다.

### 2-5. ★★ 디테일 밀도 — 작은 디테일을 「전면 금지」하지 말고 가독성을 기준으로 판단합니다

핵심 원칙은 **「작은 화면에서 정체성을 강화하는 디테일은 남기고, 노이즈만 제거한다」**입니다.

`캐릭터의 눈보다 작은 요소는 절대 금지`처럼 기계적으로 적용하지 않습니다.  
눈보다 작은 디테일이라도 **에셋의 정체성을 만드는 핵심 표식이거나 강한 대비로 읽히는 요소라면 허용**합니다.

| ❌ 피해야 할 것 | ✅ 권장 방식 |
|---|---|
| 나뭇결의 잔 무늬, 금속의 미세한 긁힘을 빽빽하게 반복 | 굵은 결 **서너 줄** + 필요한 포인트 디테일 |
| 보석 전체를 미세 면으로 잘게 분할 | **큰 면 3~5개** 중심 + 핵심 하이라이트 |
| 감은 끈·붕대의 올 하나하나 표현 | 감긴 **큰 덩어리**가 먼저 읽히게 |
| 미세한 발광 입자를 수십 개 흩뿌림 | **큰 빛 덩어리 1개 + 보조 입자 소수** |
| 전설 장식까지 단순화해 등급 차이가 사라짐 | 등급 정체성을 만드는 특이 실루엣·움직임·핵심 문양은 유지 |

**멀리서 축소했을 때 먼저 큰 실루엣과 핵심 장식이 읽혀야 합니다.**  
가까이에서만 보이는 잔디테일은 줄이되, 전설·영웅 등급의 정체성을 만드는 정보까지 삭제하지 않습니다.

### 2-6. 화풍 — 최우선 시각 기준

**첨부된 `wizard_body.png`와 같은 화풍·같은 픽셀 굵기·비슷한 가장자리 처리·비슷한 명암 밀도로 그립니다.**  
지팡이를 캐릭터 옆에 세워 놓았을 때 **같은 게임, 같은 제작 파이프라인에서 나온 에셋처럼 보여야 합니다.**

충돌이 생기면 다음 우선순위로 판단합니다.

1. 게임 레이어 정합을 위한 **길이·헤드 폭·자세 규격**
2. `wizard_body.png`와의 **시각적 화풍·픽셀 밀도·가장자리 처리 일치**
3. 등급별 실루엣과 개별 에셋의 정체성
4. 주요 팔레트와 명암 단계 가이드
5. 세부 장식의 단순화

즉, **색 수나 디테일 규칙을 맞추기 위해 캐릭터와의 화풍 일치를 훼손하지 않습니다.**

## 3. 등급의 인상

| 등급 | 인상 |
|---|---|
| **일반** | 주워 온 물건. 손질도 안 됐다 |
| **고급** | 사람이 제대로 만든 물건 |
| **희귀** | 마법이 걸려 있다. **빛나는 부분이 처음 생긴다** |
| **영웅** | 형태가 특이해지고 **주변에 기운이 돈다** |
| **전설** | 한눈에 압도된다. **스스로 움직이는 요소**가 있다 |

**등급이 오를수록 헤드가 커지고 밝아집니다. 실루엣만 봐도 등급이 읽혀야 합니다.**

단, 등급 상승을 표현한다고 해서 **헤드 폭 제한을 넘기거나 무수한 미세 입자로 화면을 채우지 않습니다.**  
전설의 고급감은 미세 장식의 양보다 **형태, 대비, 핵심 광원, 움직임의 암시**로 표현합니다.

## 5. 내보내기 전 확인 목록

각 장을 내기 전에 스스로 점검해 주세요.

- [ ] 지팡이 **길이가 캐릭터 신장의 95~100%** 인가
- [ ] **헤드가 캐릭터 얼굴(169px)보다 작은가** — 빛·입자 포함
- [ ] 등급에 맞는 **헤드 크기**인가 (70 / 90 / 110 / 130 / 150px)
- [ ] **지팡이만** 있는가 — 몸·손·팔·그림자가 없는가
- [ ] **세워 든 자세**이고 캔버스 가로 **중앙**에 있는가
- [ ] 캔버스가 **세로로 길고** 지팡이가 세로의 **약 90%**를 채우는가
