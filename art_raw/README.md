# art_raw — GPT에서 받은 원본을 여기 넣습니다

**ZIP을 풀어서 아래 폴더에 넣어 주세요. 파일 이름은 바꾸지 마세요.**

```
art_raw/
  wizard/    ← 마법사 몸·모자·로브·지팡이   (wizard_body.png, staff_c_knotted.png …)
  enemy/     ← 일반 적 26종                (enemy_green_slime.png …)
  boss/      ← 보스 13종                  (boss_elder_slime.png …)
  bg/        ← 배경 4종                   (bg_forest.png …)
  icon/      ← 주문·아이템 아이콘 (나중)
  fx/        ← 이펙트 (나중)
```

- **PNG 원본 그대로** 넣습니다. 크기를 줄이거나 형식을 바꾸지 마세요
- **`.metadata.json`도 같이** 넣습니다 (같은 이름, 같은 폴더)
- 마음에 안 들어 다시 뽑은 것은 **덮어쓰면** 됩니다

## 여기 넣은 뒤

Claude에게 **「원화 넣었어」** 한마디만 하시면 됩니다.

1. 480px 축소본을 만들어 **필요한 것만** 확인합니다 (원본을 열면 토큰이 4배)
2. 후처리(외곽선·팔레트 근사·포스터라이즈)를 걸어 **`assets/art/`** 에 WebP로 굽습니다
3. 게임 코드가 읽는 것은 `assets/art/` 쪽입니다

## 폴더가 두 개인 이유

| 폴더 | 무엇 | 게임이 읽나 |
|---|---|---|
| **`art_raw/`** | GPT가 준 **원본 PNG** + 메타데이터 | ❌ |
| **`assets/art/`** | 후처리를 끝낸 **게임용 WebP** | ✅ |

원본을 남겨 두는 이유는 **후처리 규칙이 바뀌면 다시 구워야** 하기 때문입니다.
원본을 버리면 그때 46장을 전부 다시 뽑아야 합니다.

> ⚠ 나중에 파일이 많아져 저장소가 무거워지면 `art_raw/`만 따로 빼냅니다.
> 그때까지는 여기 두는 것이 편합니다.

## 장비(지팡이·모자·로브) 검수 절차 — 2026-09-04 신설

**받은 PNG가 규격에 맞는지 재는 방법이다.** 기준값은 전부
`ASSET_LIST_EQUIP.md` 2절에 있다. 이 절은 **「어떻게 재는가」**만 적는다.

> 이 절차가 없어서 앞선 창이 매번 다시 궁리했다. 그림을 보기 전에 **먼저 재라.**
> 규격에서 떨어진 것은 눈으로 볼 필요가 없다 (토큰 절약).

### 1단계 — 눈으로 보기 전에 숫자부터 낸다

알파 채널이 0이 아닌 화소만 본다. 15종을 한 번에 표로 뽑는다.

| 재는 값 | 어떻게 | 합격선 |
|---|---|---|
| **길이** | 알파>0인 화소의 세로 범위 | 캐릭터 신장 599px의 **108~112%** = **647~671px** |
| **헤드가 내려온 깊이** | 위에서부터 **가로 폭이 몸통 굵기로 좁아지는 첫 줄** ÷ 전체 길이 | **30% 이내** |
| **몸통 폭** | 아래 40~90% 구간에서 각 줄의 알파 폭을 재 **중앙값** | 등급별 **30~42px** |
| **막힌 덩어리** | 헤드 구간에서 **가로로 끊기지 않고 이어진 알파 구간**의 최대 길이 | 등급별 **70~150px** |
| **고유색 수** | RGB 서로 다른 값의 개수 | **수천 개 이상**. 24~32개면 **강제 양자화 사고** |
| **알파 계조** | 0도 255도 아닌 알파값의 비율 | 0%면 **알파 이진화 사고** |

- **「막힌 덩어리」와 「헤드 폭」을 헷갈리지 마라.** 궤도·별처럼 틈이 많은 장식은
  넓어도 얼굴을 안 가린다. 가리는 것은 **연속된 불투명 덩어리**뿐이다
  (v1 전설 지팡이: 폭 352px이지만 최대 덩어리 138px < 얼굴 169px → 합격)

### 2단계 — 캐릭터에 실제로 합성해 본다

**숫자만으로 판정하지 마라.** `wizard_body.png` 위에 지팡이를
`UI_DESIGN.md`의 배율(**1.10**)과 앵커로 올려 합성한 그림을 만든다.

- **얼굴(피부만) 169px 폭 영역에 지팡이 알파가 겹치는가** → 겹치면 불합격
- **몸통 영역이 얼마나 덮이는가**

### 3단계 — 그때 비로소 본다

합성본을 **가로 480px로 줄여** 그것만 연다. 15종을 한 장의 대비표로 붙여
**한 번에 본다.** 원본(800×1600)을 15장 열면 한도를 태운다.

불합격은 어느 수치가 얼마나 벗어났는지를 숫자로** 적는다.
